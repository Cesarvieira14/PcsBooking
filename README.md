## Introduction
The **Pc's Booking App** is an Android application designed to optimize the allocation of shared computing resources, such as PCs or remote desktops, in environments like offices, libraries, or coworking spaces. The app allows users to book PCs in real-time, manage their bookings, and view availability, while administrators can oversee bookings, users, and machines.

This project was developed as part of my bachelor's final project at **De Montfort University**, under the supervision of **Dr. Aboozar Taherkhani**.

## Features
- **User Features**:
  - User authentication (login/register).
  - Real-time PC booking with a 7-day window.
  - Manage bookings (view, cancel, and view past bookings).
  - Forgot password functionality.

- **Admin Features**:
  - Manage bookings (view, filter, and cancel bookings).
  - Manage users (view, update roles, and delete users).
  - Manage machines (add, update, and delete machines).

## Technologies Used
- **Programming Languages**: Kotlin, Java
- **Architecture**: MVVM (Model-View-ViewModel)
- **Backend**: Firebase (Authentication, Realtime Database)
- **Tools**: Android Studio, Git
